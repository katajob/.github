# KataJob — Structured Interview Prep for Developers

Technical interview questions, answered at three depths and scheduled for review. Pick a roadmap for a
role or a skill, set a plan, learn. No account to start:
[katajob.com](https://katajob.com/?utm_source=github&utm_campaign=profile)

## What is on the site

- **Roadmaps** by role or skill, ordered from simple to advanced — e.g.
  [Java Backend Developer](https://katajob.com/roadmaps/java-developer?utm_source=github&utm_campaign=profile),
  [Kotlin](https://katajob.com/roadmaps/kotlin?utm_source=github&utm_campaign=profile),
  [Spring Boot](https://katajob.com/roadmaps/spring-boot?utm_source=github&utm_campaign=profile),
  or [all roadmaps](https://katajob.com/roadmaps?utm_source=github&utm_campaign=profile).
- **Topic hubs**: a written primer per subject and its key questions — e.g.
  [Java](https://katajob.com/topics/lang-java?utm_source=github&utm_campaign=profile),
  [SQL](https://katajob.com/topics/lang-sql?utm_source=github&utm_campaign=profile),
  [Data structures & algorithms](https://katajob.com/topics/found-dsa?utm_source=github&utm_campaign=profile).
- **Questions**, each answered three ways: the short answer, the one you would say aloud, and a
  self-contained deep dive. 90+ roadmaps · 79 topic hubs · 50,000+ questions.

## How it is made

The content is written by AI and checked by scripts; every question card has a bug icon for reporting a problem.

## Found a mistake?

Use the bug icon on the question card, or write to support@katajob.com. Content pull requests are
not accepted — the site is the source of truth.
